# Local preview

Run `python -m http.server 8765 --bind 127.0.0.1`, then open http://127.0.0.1:8765.

The site remains compatible with GitHub Pages; no build step or API key is required.
Run `npm test` for source validation, update automation, reset-boundary and timer tests.

Local storage holds notes, preferences, and session timing. Audio is off on each fresh load.
Source feeds are public third-party services; source failures and code expiry disable copying.

New visual asset: assets/terminal-frame.webp, generated for this project.
